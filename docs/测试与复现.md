## 运行命令

```powershell
$env:PYTHONPATH="backend"
.venv/Scripts/python.exe -X utf8 -m pytest backend/tests -q
cd frontend
npm test
npm run build
```

设置接口可单独运行：

```powershell
$env:PYTHONPATH="backend"
.venv/Scripts/python.exe -X utf8 -m pytest backend/tests/test_model_settings_api.py -q
```

金额校验同时覆盖规则和模型规划入口；负数或不支持的币种先澄清，不调用模型来猜金额。

本机测试模拟成功、失败、未知与重放。真实PC检验使用实际Edge与隔离FastAPI TestClient连接，未将其当作网络部署。模型设置测试不发送真实密钥；官方连通检查仅发送模拟余额查询意图，不含客户账户数据。配置与启动详见README及配置说明。

## 能力边界

六类业务是本机可运行子集，持续目标仅生日和账单续费两类。样例分公开报道参考与合成回归，未训练模型；不以测试数、资料量或合成回放冒充反诈准确率。公开版本不包含本机.env、客户数据、账户数据库或开发流水。真实银行、商户、短信/人脸验证与外部APP/IM仍未连接。
