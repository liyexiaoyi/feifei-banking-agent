# 配置说明

复制`.env.example`为本机`.env`，官方地址和`deepseek-flash`模型已预填。公开示例不包含密钥，仍可直接运行规则演示；使用模型时填入本人密钥，并把`FF_PLANNER_MODE`改为`model`。首页右上角“模型/API设置”可为本机演示配置DeepSeek官方服务，密钥不会回显或写入浏览器存储。服务器须显式设置`FF_ALLOW_MODEL_SETTINGS=1`，只有本机demo会话可保存；guest不可访问。保存仅更新本机.env，重启后生效，不会自动测试或产生模型调用。`.env`不应提交。

| 配置 | 默认/用途 |
| --- | --- |
| FF_PLANNER_MODE | rules，本机规则模式；模型模式使用显式配置的兼容Chat Completions服务 |
| FF_MODEL_BASE_URL/NAME/API_KEY | 默认`https://api.deepseek.com`、`deepseek-flash`；密钥仅存本机`.env` |
| FF_PORT | 8765，本机端口 |
| FF_CODEGEN_MODE | off；显式设为provider才开放可选WAT生成器 |
| FF_CODEGEN_ROLE | provider，服务器允许的计算模型通道 |
| FF_COORD_MODEL_BASE_URL/NAME/API_KEY | 计算生成器使用的服务器配置；协议为Messages格式 |
| FF_RUNTIME_PROXY_URL | 可选显式本机HTTP代理；不修改系统代理，不关闭TLS校验 |

应用启动、页面刷新和恢复查询不会自动发起模型生成。生成说明与参数数量可发送给所选服务，原始账户数据与计算参数值不自动发送。请仅为有授权的服务配置密钥。

HMAC渠道入口、外部强验证与商户订单仍是可测试契约/模拟适配器，不能用MCP或传输签名代替银行业务授权。

## DeepSeek 官方演示

接口固定为`https://api.deepseek.com`；模型可使用`deepseek-flash`。官方地址与模型为默认值；本仓库只保留空密钥，密钥由使用者存入服务器本机`.env`，不打包进源码或浏览器。首次启用模型须明确同意把后续对话发往官方服务。模型仍只规划白名单动作，银行权限与本人确认不变。官方接口格式见[DeepSeek接入说明](https://api-docs.deepseek.com/)。
